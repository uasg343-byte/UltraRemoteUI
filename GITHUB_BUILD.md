# Build APK on GitHub Actions

1. Create a GitHub repository.
2. Upload the contents of this project to the repository root.
3. Open **Actions**.
4. Select **Build Android APK**.
5. Click **Run workflow**.
6. When it finishes, open the workflow run and download the **UltraRemoteUI-debug-apk** artifact.

The workflow builds the local-only debug APK with Gradle on GitHub's cloud runner.
